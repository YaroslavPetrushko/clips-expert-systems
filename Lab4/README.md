## Лабораторна робота №4

### ЗАВДАННЯ
Необхідно розробити експертну систему для завдання, яке розглядається в [лабораторній роботі №3 (Завдання 2)](../Lab3/README.md), із застосуванням функцій.

*Опис змінних та функцій, що використовуються в програмі*

Глобальна змінна:
-	`?*deficiency-count*` — лічильник кількості виявлених дефіцитів поживних речовин; ініціалізується нулем, інкрементується функцією print-diagnosis при кожному новому дефіциті.

Локальні змінні:
-	`?nutrient` — зв'язується в LHS правила report-deficiency зі значенням слоту nutrient факту deficiency; передається як аргумент у функції print-diagnosis та get-recommendation.

Функції:
-	`get-recommendation (?nutrient)` — приймає символ поживної речовини, повертає (implicit return через switch) текстову рекомендацію щодо добрива. Демонструє функцію з параметром і значенням, що повертається.
- `print-diagnosis (?nutrient)` — приймає символ поживної речовини; друкує діагностичне повідомлення, викликає get-recommendation для отримання рекомендації та інкрементує глобальний лічильник `?*deficiency-count*.`
Демонструє виклик однієї функції з іншої та роботу з глобальною змінною.
-	`print-header ()` — функція без параметрів; друкує заголовок звіту на початку роботи програми.
- `print-summary ()` — функція без параметрів; аналізує значення `?*deficiency-count*` і друкує підсумкове повідомлення (є дефіцити чи ні).
-	`show-help ()` **— виводить короткий мануал з переліком усіх доступних команд системи та допустимих імен симптомів**;
демонструє функцію без параметрів і без значення, що повертається (використовується лише заради побічного ефекту — виводу).
-	`load-test-1..4 ()` — **завантаження окремого тестового сценарію**: скидання бази фактів, обнулення лічильника, внесення відповідного набору symptom-фактів.
Дозволяють перевіряти роботу системи на кількох незалежних наборах вхідних даних без перезавантаження програми.
-	`reset-counter ()` — допоміжна функція, що обнуляє глобальну змінну `?*deficiency-count*` перед кожним новим тестом (демонструє повторне використання функції з інших функцій).

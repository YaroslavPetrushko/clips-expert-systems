#### Завдання 1 - операції з фактами assert, retract, facts, reset
1.	Введіть наступні факти в базу фактів:
`(Today is Thursday)
(Tomorrow is Friday)`
2.	Перевірте що факти були введені правильно. 
3.	Приберіть перший факт. Перегляньте базу фактів.
4.	Очистіть базу фактів. Перегляньте базу фактів.

*Опис змінних та функцій*

- `assert (<Fact>)` – команда додавання факту до бази фактів
- `retract <id>` – команда для видалення факту за ID
- `facts` – команда для виведення фактів у консоль з бази фактів
- `reset` – команда для очищення бази фактів. Створює базовий факт `(initial-fact)` та завантажує факти, оголошені через `deffacts`.
  
**Текст програми**
```
(assert (Today is Thursday))
(assert (Tomorrow is Friday))
(facts)
(retract 1)
(facts)
(reset)
(facts)
```

#### Завдання 3 - прості правила; defrule, variables, printout, run, refresh,
В окремому clp-файл напишемо просте правило. 
Правило повинне відповідати наведеним вище фактами. Таким чином, Ви повинні вказати в умови правила, конструкцію з трьох елементів. На першому місці "today", на другому – «is» і на третьому місці змінна, що представляє день тижня. Як і факт така конструкція поміщається в дужки.
Синтаксис простого правила:

`(defrule <rule-name>
  <condition-patterns>
  =>
  <actions>)`

Правило повинне вивести на екран знайдений день тижня. Для цього в розділі actions використовуйте функцію `(printout t "..." crlf)`.
Використовуйте факти зі списку фактів deffacts і подивитися, чи працює правило (Run).Ви можете перевірити можливість спостерігати за правилом активації. Правило повинне надрукувати "Today is Thursday".

*Опис змінних та функцій*
- `defrule <rule-name> <condition> => <actions>` – конструкція оголошення продукційного правила формату LHS (умови) => RHS (дії). 
- `printout` – функція виведення даних. Параметр t вказує на стандартний потік виведення (консоль), crlf – перенесення на новий рядок.
- `run` – запускає виконання програми та активних правил.

#### Завдання 4 * - впорядковані факти; deftemplate з multislot, type, allowed-values
Доповніть шаблон, створений в завданні 4 за допомогою мульти слотів і інформації про тип: слот з ім'ям визначте, як multislot; для слота з віком вкажіть тип INTEGER, і для слота з інформацією в поле перерахуйте явно допустимі значення `(allowed-values male female)`.
Приклад для deftemplates з цими слот-обмеженнями є:
```
(deftemplate <template-name>
  (multislot <slot-name>)				
  (slot <slot-name> (type INTEGER))		
  (slot <slot-name> (allowed-values <list-of-values>))
)
```
Змініть частину deffacts відповідним чином і збережіть файл під новим ім'ям. Перевірити в оболонці CLIPS чи працює належним чином визначення нових фактів.
Примітка: для того, щоб CLIPS перевіряв на тип-порушення, Вам необхідно встановити динамічну перевірку обмежень `(dynamic-constraint-checking)` В параметрах виконання (Виконати -> Виконання ...).

*Опис змінних та функцій*
- `multislot` – багатозначне поле, для зберігання списку з одного або кількох елементів.
  - `(type INTEGER)` – обмеження типу даних. Дозволяє записувати в слот виключно цілі числа.
  - `(allowed-values male female)` – обмеження списку дозволених значень. Спроба вказати інше значення викличе помилку валідаціїї.
  - `(set-dynamic-constraint-checking TRUE)` – функція ввімкнення динамічної перевірки обмежень типів і значень під час додавання фактів.

#### Завдання 5 - правила для пошуку
Створіть правила для пошуку людей відповідно до певним характеристикам, наприклад, правилa "find-men" і "find-woman", яке в списку людей знаходять чоловіків і жінок. Кожне з правил збережіть в окремий файл.
Умовну частину правил сформулюйте відповідно до фактів на основі шаблону з завдання 4, наприклад
`(person (...) (...))`
де (...) визначає слот обмеження, наприклад, `(name Berta)` для слота одного поля з одним значенням, або `(name Berta Ida)` для мульти слота з декількома значеннями. Ви також можете використовувати змінні, щоб встановити значення слота факту, як `(name? name)`, який відповідає умові.

Примітка: Для декількох слотів, ви повинні використовувати `$?<variable>`, наприклад `(name $?name)`.

Примітка: В умові Ви можете вказати тільки ті слоти, за якими проводите пошук. Інші слоти ви можете опустити.
Сформулюйте правила для пошуку людей з певним ім'ям і певним віком.

*Опис змінних та функцій*
- `?gender, ?age` – одномісні змінні для зіставлення з одиничними слотами.
- `$?name` – мультизмінна, призначена для зв’язування вмісту multislot.

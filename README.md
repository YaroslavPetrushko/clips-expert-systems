# Експертні системи на базі CLIPS
Практичні роботи з дисципліни «Інтелектуальні інформаційні технології».

Репозиторій містить результати розробки баз знань та правил у середовищі CLIPS в рамках дисципліни «Інтелектуальні інформаційні технології».

## Структура репозиторію
- `Lab1/` – операції з фактами (assert, retract, facts);
- `Lab2/` – створення шаблонів (deftemplate) та впорядковані факти;
- `Lab3/` – формування бази правил (defrule) експертної системи;
- `Lab4/` – створення та використання функцій (deffunction);
- `Lab5/` – дерева рішень та логічне виведення;
- `README.md` – опис проєкту.

## Висновки
У ході виконання лабораторної роботи було проведено ознайомлення з системою контролю версій Git та сервісом GitHub і застосовано їх для збереження результатів розробки експертних систем у середовищі CLIPS. Створено публічний репозиторій clips-expert-systems, сформовано структуру з окремими папками Lab1–Lab5 та завантажено файли з фактами, шаблонами, правилами й функціями, розробленими під час виконання перших п'яти лабораторних робіт.

Опановано основні поняття та операції: репозиторій, коміт із описом змін, створення папок через вебінтерфейс, завантаження файлів та оформлення README.md мовою Markdown. З'ясовано, що Git не зберігає порожні папки, тому кожну папку було створено разом із файлом README.md. Окремі README у кожній папці містять умову завдання, опис змінних і функцій та посилання на код, що робить репозиторій самодокументованим.

Збереження проєкту на GitHub забезпечило резервну копію, історію змін і зручний доступ для перевірки одним посиланням. Єдина структура репозиторію наочно показала розвиток експертних систем від простих фактів і шаблонів до правил, функцій та дерева рішень. Набуті навички можна застосовувати для командної роботи та ведення власних проєктів.
